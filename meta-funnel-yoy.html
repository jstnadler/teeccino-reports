🔍 Google Ads — Funnel YoY

Google has no audience-tag naming convention like Meta, so classification leans on campaign_type + explicit "TOF" name tags. PerformanceMax dominates Google spend (~70%) and is intentionally a mixed-funnel black box — Google blends cold/warm/retargeting based on its model, so PMax cannot be cleanly disaggregated by audience.

Google funnel buckets: TOF (Cold) = DEMAND_GEN + DISPLAY + PMax campaigns with explicit "TOF" in name · PMax (Mixed) = PERFORMANCE_MAX without TOF tag (Google decides the mix) · Shopping = SHOPPING type (intent-aware buyers) · Non-Brand Search = SEARCH campaigns targeting non-brand keywords · Brand Search (BOF) = SEARCH campaigns on branded keywords (people typing "Teeccino").
