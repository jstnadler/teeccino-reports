How this is built

Adds: raw_ga4_atc (GA4 add_to_cart by source). Purchases: raw_line_items.atc_source — the hidden _atc_source line-item property ThemeSmith stamps at add time (live 2026-06-08), which persists onto the Shopify order. True Gross = units × price-list MSRP (paid lines only); Margin = True Gross − COGS.
Days to Conversion: calc_attribution.days_to_conversion, which carries Shopify's customerJourneySummary.daysToConversion — first recorded visit to first order, new DTC customers only. It is a separate basis from the funnel above and is deliberately not split by source: the journey uses Shopify's visit UTM vocabulary, not the _atc_source property, and it reaches back years rather than starting at the tracking live date. Joining the two would invent a precision neither side has.
Conv % = units purchased / units added. The two are different grains (GA4 browser events vs realized Shopify orders), so read it as a directional trend by source, not an exact funnel ratio.
