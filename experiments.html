How this page is built

Intelligems snapshot

Backlog
Hypotheses live in data/backlog.json, ranked by PXL. Status flows ranked → in-design → running → won/lost/inconclusive.
JSON feed: experiments-data.json
HubSmith may consume experiments-data.json (counts / running / winners / losers / backlog) instead of iframing this page.
