What you're looking at

  1. As first generated it is not a bag — it is a T of flat slabs. (Four cycles of correction change this; see the loop below.) Every component the spec called extrude or plane-card came out as a card, so there is no pouch volume at all: no pillow bulge, no gusset, no side creases. Straight-on it can pass for a moment; a few degrees of rotation ends that.
  2. All the recognisability is your photograph. The albedo map the pipeline extracted is the reference image, de-lit. The colours it derived from the pixels are correct, though: #40600E #C2BD93 #B5654A.
  3. The tiling is the tell. At the spec's default textureProjection.repeat [2,2] each slab is wallpapered with a 2×2 grid of tiny French Roast bags — visible on the still below.
  4. It passed its own strict gate. validate_sculpt_spec.py --strict-quality returned PASS / exit 0 on this. The gate checks the spec is richly described, not that the render resembles anything — likeness lives in a separate 5–8 cycle vision loop (~80–180k tokens).
  5. You cannot easily get the photo out — and the gate won't let you. Deleting materials[].albedo.map from the spec and regenerating leaves the photograph fully intact, because a second copy lives at materials[].referencePbr.maps.albedo (middle button — the spec edit looks like it worked and changes nothing). Strip referencePbr as well and you get the genuinely photo-free build (third button) — which then FAILS --strict-quality with "material 'base' needs usable referencePbr extracted from source pixels." The gate requires the field that keeps the photo in.
  6. No fabricated brand text — this time. It never drew text; it pasted the photo. The falsification risk arrives the moment you push it through the surface pass to build that label procedurally.

The correction loop — 4 cycles, run 2026-08-05

Each cycle: render → inspect against the reference → name the defect → fix the spec → regenerate. The headline is that it got structurally righter and texturally worse, and the two are in direct tension.

Cycle 1 — volume appears

Found: everything was a flat 0.6×0.6 card. Cause: the codegen reads geometryDescriptor.profile2D and silently falls back to _DEFAULT_EXTRUDE_PROFILE when it is missing — my spec never authored one, and --strict-quality does not check for it. Fix: authored pouch cross-sections. Volume arrived, but the parts flew apart.

Cycle 2 — it reads as the product

Found: body off-frame, texture still wallpapered 2×2. Cause: a sign error in my own offset, plus textureProjection.repeat left at the scaffold default. Fix: both. First render that looks like French Roast — with 5 decal cards still floating beside it.

Cycle 3 — best front, and the gate turns on it

Found: the label/logo/linework cards each re-drew the whole bag photo. Cause: with a projected reference albedo the artwork is already on the surface — decal geometry and photo projection are mutually exclusive, and nothing in the pipeline says so. Fix: deleted them. The front is now clean — and the spec now FAILS --strict-quality: "mesoComponents below qualityContract minimum (2 < 3)". Removing the wrong geometry made the render better and the score worse.

Cycle 4 — correct geometry, ruined texture

Found: the bag lay on its side, the seal was a unit 1×1×1 cube. Cause: three more of my own errors — rotation set on yaw not pitch, the box primitive ignoring dimensions{} (only transform.scale is read), and a visible:false field I invented that no schema reads. All three accepted silently. Result: upright and correct — and the extrude side-wall UVs now wrap the photograph mirrored and upside down. There is no planar front-projection UV mode for a generic object; that path exists only for CS2 weapons and characters.

Where the loop lands. Four cycles bought a real pouch volume and a front view that reads as the product — but every gain came from me supplying geometry the reference photo cannot contain, and the best-looking build is the one its own gate rejects. The ceiling is not effort; it is that a single front photo has no back, no depth, and no way to project onto volume without a UV mode this pipeline only ships for weapons.
