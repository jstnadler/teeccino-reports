Pipeline Status & Schema

Source table: raw_ga4_atc
Populated by ingest_ga4.py from the GA4 Data API. One row per (date, atc_source, item_id). ingest_ga4 filters to attributed events (atc_source / item_list_name in the source vocab) so the parallel Shopify Web Pixel add_to_cart is never double-counted.
Cart value is computed, not from GA4
GA4's itemRevenue metric is purchase-scoped and returns 0 for add_to_cart, so adds carry no native dollar value. We value each add ourselves: GA4's item_id is the Shopify product ID, joined to shopify_products.default_price (the catalog, refreshed nightly by fetch_product_prices.py). Value = quantity × default-variant price. Adds are product-grain (the added variant is unknown), so the default-variant price is a representative estimate, not an exact basket value.
JSON feed: atc-source-data.json
HubSmith's custom teeccino-reports page consumes the same atc-source-data.json this builder writes (by_source / trend / by_product / by_source_product).
